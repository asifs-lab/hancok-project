# 🎮 Hancok - Gaming Website

Welcome to **Hancok**, a modern gaming community website designed for gaming enthusiasts. This project showcases a gaming platform with an attractive user interface, game collections, live streaming sections, gaming accessories, and professional gaming teams.

## 🌐 Live Demo

[Visit Hancok Website](https://asifs-lab.github.io/hancok-project/)

## ✨ Features

- 🎮 Modern Gaming Website Design
- 👥 Gaming Community Section
- 📺 Live Streaming Section
- 🕹️ Popular Games & Game Catalog
- 🎧 Gaming Accessories Showcase
- 🏆 Professional Gaming Team Section
- 📩 Newsletter Subscription Section
- ❓ FAQ Section

## 🛠️ Technologies Used

- HTML5
- CSS3
- Google Fonts
  - Oswald
  - Barlow Condensed
- Font Awesome Icons

## 🚀 Getting Started

Follow these steps to run the project locally.

**1. Clone the repository**

```bash
git clone https://github.com/asifs-lab/hancok-project.git
```

**2. Open the project folder**

```bash
cd hancok-project
```

**3. Open the website**

Open `index.html` in your browser or use the Live Server extension in VS Code.
